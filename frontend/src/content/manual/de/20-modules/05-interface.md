# Workspace-Liste

![Die Workspace-Liste mit den eigenen Workspaces](/manual/{lang}/module-list.png)

- Erreichbar über die Kachel **KI-Assistent Francis** auf der Startseite. Wer außer dem
  Assistenten nichts freigeschaltet hat, landet nach der Anmeldung direkt hier
- **Rechts oben**: Kalender, Jobs, Zahnrad (Sprache, Hell/Dunkel, Dokumentation, Abmelden, bei
  Rechten zusätzlich Statistik oder Verwaltung)

## In einen Workspace kommen

![Beitreten mit Link oder Code](/manual/{lang}/join-module.png)

Neben **+ Workspace** sitzt **Beitreten**. Dort setzen Sie ein, was Sie bekommen haben, die ganze
Adresse oder nur den Code daraus.

- Groß oder klein geschrieben ist egal, ein Leerzeichen mitten im Code stört auch nicht
- Ein unbekannter Code sagt das im Fenster, die Seite wechselt nicht
- Danach kommt die Einschreibekarte mit Workspace-Name und Lehrperson, erst der Knopf darauf schreibt
  Sie ein
- Wer noch in keinem Workspace ist, findet dasselbe Feld direkt in der leeren Liste

## Aktiv und inaktiv

Der Schalter hinter jedem Workspace sperrt ihn für Teilnehmende. Nichts wird gelöscht, ein Klick gibt
es wieder frei.
