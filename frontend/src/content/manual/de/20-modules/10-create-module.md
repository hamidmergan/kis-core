# Ein Modul anlegen

![Ein neues Modul anlegen](/manual/{lang}/create-module.png)

Auf der Startseite über **+ Modul**, mit Name und kurzer Beschreibung.

## Teilnehmende hereinholen

Niemand wird von Hand eingetragen. Sie erzeugen einen **Einschreibelink** und geben ihn weiter.
Wer ihn öffnet, schreibt sich selbst ein.

Jeder Link steht zweimal da, als ganze Adresse und als kurzer Code daneben, beides mit einem Klick
kopiert. Der Code ist für die Wege ohne Klick, auf einer Folie, an der Tafel, im Seminar
vorgelesen. Damit kommt man über **Beitreten** auf der Startseite herein.

## Freigeben aus dem Modul heraus

![Freigeben im geöffneten Modul](/manual/{lang}/share-module.png)

Im geöffneten Modul sitzt neben dem Zahnrad ein Knopf **Freigeben**. Er legt Einschreibelinks und
Teilnehmerliste in ein Fenster, dazu den Schalter aktiv, damit ein Link nicht ins Leere führt.
Eigentümer und Tutoren sehen ihn, sonst niemand.

Unter Teilnehmer machen Sie einzelne Personen zu **Tutoren**. Tutoren dürfen alles außer löschen
und weitere Tutoren ernennen.

## Das Menü der Modulzeile

- **Teilnehmer**: Liste, Tutoren ernennen
- **Einschreibelinks**: Zugänge erzeugen und zurückziehen
- **Bearbeiten**: Name und Beschreibung
- **Löschen**: endgültig, mit allem was daranhängt
