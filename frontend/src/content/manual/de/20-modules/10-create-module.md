# Einen Workspace anlegen

![Einen neuen Workspace anlegen](/manual/{lang}/create-module.png)

Auf der Workspace-Liste über **+ Workspace**. Der Titel darf 50 Zeichen lang sein, die
Beschreibung 500 Zeichen.

- Der erste Einschreibelink entsteht gleich mit. Das Datum im Fenster ist seine Laufzeit, leer
  heißt unbegrenzt
- Ein neuer Workspace ist zunächst inaktiv. Erst der Schalter in der Liste lässt Teilnehmende
  hinein

## Teilnehmende hereinholen

Niemand wird von Hand eingetragen. Sie geben einen **Einschreibelink** weiter, wer ihn öffnet,
schreibt sich selbst ein.

Jeder Link steht zweimal da, als ganze Adresse und als kurzer Code daneben, beides mit einem Klick
kopiert. Der Code ist für die Wege ohne Klick, auf einer Folie, an der Tafel, im Seminar
vorgelesen. Damit kommt man über **Beitreten** auf der Workspace-Liste herein.

- **Höchstens 10 Links** je Workspace, jeder mit eigener Laufzeit. Für einen neuen muss ein alter
  weg
- **Getrennte Chatverläufe**: Wer sich über verschiedene Links einschreibt, sieht im Chat nur
  die eigene Gruppe. So lassen sich zwei Kurse mit demselben Material trennen
- Ein abgelaufener Link steht durchgestrichen in der Liste
- Einen Link **löschen** macht ihn ungültig, wer sich darüber eingeschrieben hat, bleibt drin
- **100 Mitglieder** je Workspace, danach trägt die Zeile in der Liste den Vermerk Voll

## Freigeben aus dem Workspace heraus

![Freigeben im geöffneten Workspace](/manual/{lang}/share-module.png)

Im geöffneten Workspace sitzt neben dem Zahnrad der Knopf **Freigeben**. Er legt Einschreibelinks und
Teilnehmerliste in ein Fenster, dazu den Schalter aktiv, damit ein Link nicht ins Leere führt.
Eigentümer und Tutoren sehen ihn, sonst niemand.

Unter Teilnehmer machen Sie einzelne Personen zu **Tutoren**. Tutoren dürfen alles außer löschen
und weitere Tutoren ernennen. Ernennen kann nur die Eigentümerin oder der Eigentümer.

## Das Menü der Workspace-Zeile

- **Teilnehmer**: Liste, Tutoren ernennen
- **Einschreibelinks**: Zugänge erzeugen und zurückziehen
- **Bearbeiten**: Titel und Beschreibung. Bei einem Demo-Workspace steht hier zusätzlich der Haken
  **Workspace für den Rundgang**. Der Rundgang startet dann in diesem Workspace, jeder andere
  Demo-Workspace verliert den Haken
- **Löschen**: nur für Eigentümer, endgültig, mit allem was daranhängt. Die Rückfrage nennt, wie
  viele Teilnehmende dabei ihre Chatnachrichten und Notizen verlieren
