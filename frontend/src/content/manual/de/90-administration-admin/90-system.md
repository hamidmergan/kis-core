# System

Drei Schalter für die ganze Plattform.

- **Wartungsmodus**: an heißt, alle ohne das Recht Zugriff während der Wartung bekommen eine
  Wartungsseite statt der App. Nötig zum Beispiel vor einem Neu-Indexieren der Materialien.
- **Hinweis auf Startseite**: ein Text als Leiste über dem Menü, bei allen Personen, aufklappbar,
  eingeklappt steht dort nur das Wort Hinweis. Links im Text stehen als [Beschriftung](Adresse).
  Ein leeres Feld heißt, auch bei eingeschaltetem Schalter bleibt der Hinweis verborgen.
- **Begrüßungsfenster beim ersten Login**: ein Text, der jedem Konto genau einmal direkt nach der
  allerersten Anmeldung angezeigt wird, danach nicht wieder. Wer es sieht, braucht zusätzlich ein
  eigenes Recht in der Rechtematrix.
