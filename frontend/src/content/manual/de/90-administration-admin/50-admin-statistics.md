# Statistik

Unter Statistik stehen Zahlen zum Lesen, fünf Reiter, jeder an ein eigenes Recht gebunden.
Eingestellt wird hier nichts.

- **Nutzer**: wer gerade online ist, der Tagesverlauf, Online je Tag, neue Konten je Monat,
  Rollen, dazu eine Einzelansicht je Person.
- **Dienste**: Aufträge je Dienst, Auslastung nach Wochentag und Stunde.
- **Lernassistent**: Workspaces, Übungen, Chat, Niveaus, Materialien, Tools, auch je einzelnem
  Workspace.
- **Modelle**: Aufrufe und Token je Modell und Anbieter. Erfasst wird bisher nur Chat.
- **Evaluation**: Teilnahmen, nummeriert statt mit Namen.
