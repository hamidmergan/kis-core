# Zugangscodes und Einladungen

Zwei Wege, Personen ohne zentrale Anmeldung ein Konto zu geben. Beide brauchen den Server-Schalter
für die Kontoanlage, ist er aus, steht hier nur ein Hinweis, dass beides abgeschaltet ist.

## Einladungen

Ein einzelner Link für eine Person. Titel ist der Benutzername, meist Vorname.Nachname oder ein
Kürzel, die E-Mail-Adresse ist freiwillig. Dazu Rolle und Gültigkeit in Tagen. Der Link löst sich
genau einmal ein, danach steht er auf Eingelöst, eine noch offene Einladung lässt sich zurückziehen.

## Zugangscodes

Ein Code für eine ganze Testrunde oder Veranstaltung, mehrere Personen lösen denselben Code ein.

- **Titel, wie oft einlösbar, Code gültig** (Tage), **Zugang gültig** (Stunden oder unbegrenzt),
  **Rolle**.
- **Zugangsdaten anzeigen**: aus heißt, die Person wird beim Einlösen direkt angemeldet, ohne
  Benutzername und Passwort zu sehen, gedacht für Veranstaltungen mit einem QR-Code am Beamer.
- **Evaluation anzeigen**: an heißt, Konten aus diesem Code bekommen die Evaluation auf der
  Startseite angeboten.
- **Workspaces**: wer den Code einlöst, wird sofort in die hier gewählten Workspaces eingeschrieben.
- Jeder Code zeigt sein eigenes QR-Bild zum Herunterladen. Aus- und Einschalten, Bearbeiten (alles
  außer dem Code selbst) und Löschen sind jederzeit möglich, meist reicht Ausschalten, dann kommt
  niemand Neues mehr dazu und die bisherigen Konten bleiben sichtbar.
- Je Code die entstandenen Konten mit Status, Gilt bis, Löschung am, ein neues Passwort lässt sich
  setzen, dazu die Aktivität der Person: besuchte Workspaces, die letzten 50 Chat-Einträge.
- **Abgelaufene Testkonten löschen**: wie viele Tage nach Ablauf ein gesperrtes Testkonto endgültig
  gelöscht wird, mit Workspaces, Chats und Dateien. Antworten aus der Evaluation bleiben dabei
  anonym erhalten. Ab Werk 30 Tage, 0 heißt nie.
