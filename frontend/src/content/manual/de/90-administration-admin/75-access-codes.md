# Zugangscodes und Einladungen

Zwei Wege, Personen ohne zentrale Anmeldung ein Konto zu geben. Beide brauchen den Server-Schalter
für die Kontoanlage.

## Einladungen

Ein einzelner Link für eine Person, mit Benutzername, freiwilliger E-Mail-Adresse, Rolle und
Gültigkeit. Der Link löst sich genau einmal ein, eine noch offene Einladung lässt sich
zurückziehen.

## Zugangscodes

Ein Code für eine ganze Testrunde oder Veranstaltung, mehrere Personen lösen denselben Code ein.
Dazu Titel, wie oft einlösbar, Gültigkeit von Code und Zugang, Rolle und die Workspaces, in die
Einlösende sofort eingeschrieben werden. **Zugangsdaten anzeigen** aus heißt, die Person wird
direkt angemeldet, ohne Zugangsdaten zu sehen, gedacht für Veranstaltungen mit QR-Code.

Die Gültigkeit des Codes wählen Sie aus der Liste oder geben eine eigene Zahl von Tagen ein.

Jeder Code zeigt sein QR-Bild als Aufsteller zum Herunterladen, lässt sich aus- und einschalten,
bearbeiten und löschen. Je Code sehen Sie die entstandenen Konten mit Status und können ein neues
Passwort setzen. **Alle Konten** zeigt die Konten aller Codes in einer Liste. Dort und je Code
sperren Sie die Anmeldung einzelner Konten oder aller Konten auf einmal, offene Sitzungen enden
dabei sofort. Ebenso lassen sich einzelne oder alle Konten samt Workspaces, Chats und Dateien
löschen.
Abgelaufene Testkonten werden nach einer einstellbaren Frist automatisch gelöscht, Antworten aus
der Evaluation bleiben dabei anonym erhalten.
