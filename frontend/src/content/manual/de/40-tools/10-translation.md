# Übersetzung

Übersetzt ganze Dokumente in eine andere Sprache. Layout und Formatierung bleiben erhalten, aus
einer Präsentation wird also wieder eine Präsentation.

![Der Dienst Übersetzung](/manual/{lang}/tool-translation.png)

## Ausgangssprache und Dauer

Die Ausgangssprache erkennt der Dienst automatisch, Sie wählen nur die Zielsprache.

Große Dokumente dauern einige Minuten, danach steht die Übersetzung zum Herunterladen bereit.

## Fachbegriffe festlegen

Wenn ein Fachwort immer gleich übersetzt werden soll, legen Sie vorher im Dienst Glossar eine
Begriffsliste an und wählen sie hier aus.
