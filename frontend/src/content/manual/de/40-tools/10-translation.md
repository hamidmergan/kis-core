# Übersetzung

Übersetzt ganze Dokumente in eine andere Sprache. Layout und Formatierung bleiben erhalten, aus
einer Präsentation wird also wieder eine Präsentation.

![Das Werkzeug Übersetzung](/manual/{lang}/tool-translation.png)

## So geht es

Datei auswählen, Zielsprache wählen, auf Übersetzen klicken. Die Ausgangssprache wird
automatisch erkannt, Sie müssen sie nicht angeben.

Große Dokumente dauern einige Minuten. Danach steht die Übersetzung zum Herunterladen bereit.

## Fachbegriffe festlegen

Wenn ein Fachwort immer gleich übersetzt werden soll, legen Sie vorher im Werkzeug Glossar eine
Begriffsliste an und wählen sie hier aus.
