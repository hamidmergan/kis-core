# Signing in and registering

![The sign-in form](/manual/{lang}/sign-in.png)

## No self-registration yet

Your university credentials do not work yet, KIS currently has its own user management. Until it
is connected to the university, you only get an account through an invitation, in one of two ways:

- **Invitation link**: you set your own password, the account stays
- **Access code**: user name and password are generated and shown only once. Depending on the
  code, access expires on a date you see after redeeming

You can sign in with either the user name or the mail address.

## With an access code

- **Redeeming**: The With access code tab above the sign-in form only appears while the
  administration has access codes switched on
- **Link or QR code**: If the code is already in the link, it redeems itself without a click. Only
  if that fails, for example with an expired code, the form appears with the message
- **Events**: Codes without credentials lead straight into the app, with no user name and password

## When it does not work

- **"Account not yet activated":** the account exists but is not released. The page says whom to
  contact
- **Forgotten password:** no reset button, contact the person who invited you
- **Access expired:** The sign-in page shows a box with a mail address. You cannot extend the
  access yourself
