# Signing in and registering

![The sign-in form](/manual/{lang}/sign-in.png)

## No self-registration yet

Your university credentials do not work yet, KIS currently has its own user management. Until
it is connected to the university, you only get an account by invitation, through the person
running the course.

- **Invitation link**: set your own password, account stays
- **Access code**: user name and password are generated and shown once. Access for the test
  period, expires, renewable with a valid code

## When it does not work

- **"Account not released yet":** account exists, not released. The page says whom to contact
- **Forgotten password:** no reset button, contact the person who invited you
- **Access expired:** renewal page, enter a valid access code there

> Planned: connection to the university's central sign-on. Then the university account is
> enough, no invitation needed.
