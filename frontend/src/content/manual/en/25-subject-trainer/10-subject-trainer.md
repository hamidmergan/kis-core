# What the technical language trainer is

![The tiles in the studio](/manual/{lang}/studio.png)

Four tools in the Tools tab of the studio: Flashcards, Quiz, Data table, Mind map. Each builds
something different out of the ticked materials.

Unlike the language trainer this is about the **content** of the subject, not the language. It
is there in every workspace, no release needed.

## How a set comes about

![The window while creating](/manual/{lang}/create-set.png)

- **Flashcards and Quiz** ask for the count, 5, 10 or 15 items. Flashcards can also be built from
  the glossary of the workspace instead of the materials
- **Mind map and Data table** only ask for an instruction, and it is optional

The generation runs in the background. Finished sets then sit below the tile and under Recent
activity. The title can be changed later, with the pencil or by double-clicking the title.

## How much material is read

There is no limit on the number of ticked materials. How much of it is read depends on the tool:

- **Flashcards and Quiz** read a fixed amount of text per item, for a set of 15 items about
  100,000 characters. If not everything fits, KIS remembers per material where it stopped and
  continues there with the next set. Over several sets every file gets its turn. That position
  belongs to the workspace, not to the person
- **Mind map and Data table** read everything that fits into one call, 500,000 characters by
  default. If the material is larger, they work from the summaries KIS has created for every
  material

In the legend below a mind map or data table, materials nothing was used from are greyed out.

## The instruction

When creating a set you can add an instruction of up to 500 characters. For Flashcards and Quiz
only on the way through the materials, not from the glossary. KIS sorts it first:

- **A topic**, such as "only chapter 3": KIS looks for the matching passages in the material and
  uses only those
- **A wish about the kind**, such as "easy questions" or "columns: term, deadline, consequence":
  the material stays as it is, the wish goes into the task
- **A topic the material lacks**: the instruction is dropped. The result carries a note that the
  sources say nothing about it and all of the material was used instead
- **Nonsense or an attempt to leave the sources**: dropped silently

The finished result shows the instruction it was made with.

## The item stock

KIS collects flashcards and quiz items made from materials in a stock, kept apart per material,
tool and language level. The same goes for vocab cards, vocabulary and grammar exercises in the
language trainer, but not for mind map and data table.

- **Only after 20 generations** for a material does the stock hand anything out. Until then every
  set is made fresh
- **After that** sets come wholly or partly from the stock. That is why they are sometimes ready
  at once
- **Never anything known**: from the stock nobody gets an item that person has already had
- **Never with an instruction**: a set with an instruction is always made fresh

## When a set fails

The card turns red. Try again starts over with the same settings and counts as a new generation
against the quota.

## At most 100 per tool

Per tool and workspace every person keeps up to 100 sets. At the limit the button says to delete
one first.
