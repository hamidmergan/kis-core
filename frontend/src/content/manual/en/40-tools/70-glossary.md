# Glossary

Here you keep your own term lists, so technical terms are translated the same way everywhere.

![The glossary tool](/manual/{lang}/tool-glossary.png)

## Creating a glossary

A new one starts with **+ New glossary**. An entry consists of the German and the English
term.

## Where it takes effect

In the translation tool you pick a glossary. The terms stored there are then translated the way
you decided, instead of the way the machine thinks is right.

## Import and export

A glossary can be exported as JSON and read back in. That way you pass a well kept list on to
colleagues.

## Limits

The number of glossaries and the number of entries per glossary are limited. The counter below
the list shows the state.

## Do not mix them up

This glossary serves the translation. The glossary in the studio of a module is something else:
it collects the technical terms of the module and is the basis for vocabulary cards and
vocabulary exercises.
