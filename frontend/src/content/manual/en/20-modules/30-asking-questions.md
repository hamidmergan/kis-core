# Asking questions

![The chat with a question and an answer](/manual/{lang}/chat.png)

Type the question, send it. Above the field on the right you see how many sources are active.
Without an active source nothing can be sent. A message may be 8,000 characters long.

While the chat is empty, Francis greets you.

## While the answer comes

- First it says **Searching the workspace**, then **Generating the answer**
- The send button turns into **Stop**. Whatever was written up to then stays and is marked Stopped
- If the answer fails, **Retry** sits below it, for the newest question only

## From the materials only

If something is not in the materials, the chat says so instead of making it up. A question about
grammar therefore stays unanswered as long as no grammar material is uploaded.

## Follow-up questions

"Explain the second point in more detail" works, the chat resolves the reference.

## With an answer

- **Copy** to the clipboard, without the citations
- **Save as note** files it in the studio
- **Show all citations** reveals where every sentence came from

Older long answers are collapsed, only the last two stand in full. **Show more** unfolds them.

## The history

The history is kept per workspace and person. Whoever enrolled through different enrollment links
has one history per link. Before a new, independent question it pays to **clear the chat log**
through the three dots, otherwise the chat keeps the old question in mind.

## The mascot

![Francis in his five moods](/manual/de/mascot-states-francis.png)

The picture sits above the newest answer and shows what the chat is up to. From left to right:

- Idle, for an answer without citations
- Thinking, while the answer is being written
- Found it, when the finished answer carries citations
- Confused, when the materials say nothing about the question
- Waving, while the chat is still empty

Only the newest answer carries the picture, older ones stand without it.
