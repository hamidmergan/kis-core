# Start page

![The start page with your own modules](/manual/{lang}/start-page.png)

- **Left**: the tools
- **Top right**: calendar, jobs, gear (language, light/dark, documentation, sign out, plus
  statistics or administration if you have the right)

## Getting into a module

![Joining with a link or a code](/manual/{lang}/join-module.png)

Next to **+ Module** sits **Join**. Paste in what you were given, the whole address or just the
code from it.

- Upper or lower case makes no difference, and a space in the middle of the code does no harm
- An unknown code says so inside the window, the page does not change
- After that comes the enrolment card with the module name and the teacher, only the button on it
  enrols you
- If you are not in any module yet, the same field sits right in the empty list

## Active and inactive

The switch behind each module locks it for participants. Nothing is deleted, one click releases
it again.
