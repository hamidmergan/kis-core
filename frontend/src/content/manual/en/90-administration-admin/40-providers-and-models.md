# Providers and models

Under Providers and models sit the access to the AI providers and the question which model takes
on which task.


## Providers

A provider is a service with an address and a key. After saving, KIS only shows the last six
characters, the full key does not appear again.

## Models per task

The platform has several kinds of tasks, for example chat, translation, reading aloud and
images. You choose a model for each. It does not have to be the same one everywhere.

## Effect

Changes take effect immediately for everybody. There is no preview and no test mode.
