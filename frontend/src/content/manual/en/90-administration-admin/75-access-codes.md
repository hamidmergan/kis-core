# Access codes and invites

Two ways to give people an account without a central login. Both need the server switch for
account creation.

## Invites

A single link for one person, with username, optional email address, role, and validity. The
link redeems exactly once, a still-open invite can be withdrawn.

## Access codes

A code for a whole test round or event, several people redeem the same code. Plus title, how
often redeemable, validity of code and access, role, and the workspaces redeemers are enrolled in
right away. **Show credentials** off means the person is logged in directly without seeing
credentials, meant for events with a QR code.

You pick the validity of the code from the list or enter your own number of days.

Each code shows its QR image as a poster to download, can be switched on or off, edited, and
deleted. **Accounts created** shows the accounts a code created with status, and you can set a
new password. There you can block the login of single accounts or of all accounts of the code at
once, open sessions end right away. Single or all accounts can also be deleted along with their
workspaces, chats and files. Expired test
accounts are deleted automatically after a configurable period, with evaluation answers staying
on anonymously.
