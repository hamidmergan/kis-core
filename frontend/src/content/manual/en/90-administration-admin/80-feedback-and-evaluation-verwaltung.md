# Feedback and evaluation

## Feedback

Under Users at Feedback you read what people submitted through Report a bug or share an idea:
category (bug, idea, other), message, attachments, and, if given, contact or username. An entry
is Open, On hold or Done and can be deleted. As long as one entry is open, a red dot in the menu
and in the admin sidebar points to it.

## Evaluation

One single evaluation for the whole platform, question by question, a 1-to-5 scale or free text.

- **Active**: off means the tile and the link to fill it in are invisible to everyone.
- **Visible to everyone**: off means only accounts from an access code with the evaluation display
  switched on, and admins, see it. Switching it on also brings back anyone who had already
  dismissed the tile.
- **Title**, a text at the start and at the end, the end text with an optional link, plus any
  number of questions.
- The results show the answers without an account, under Statistics in the Evaluation tab. The
  invitation on the tile only appears once a person has really tried something, not right after
  signing in.
