# The language test

The language test estimates how well you already know German. The result is a level from A1 to
C2.

![A question in the language test](/manual/{lang}/language-test.png)

## When it comes

The card Language trainer above the workspace list is shown to everyone whose role holds the
permission Own language level and language test, teaching staff as well as students. The
administration must have switched the language trainer on. Start the language test begins the
test at once. Hide switches the language trainer off, the card does not come back. It can be
switched on again under Language level, where the test can then be started at any time.

## How it runs

The questions come from a fixed plan the administration maintains, 12 questions by default. No AI
is involved in asking them, only the placement at the end is an AI call. Four kinds appear:

- **Single choice**: one click on the answer submits it
- **Multiple choice**: tick several, then Submit
- **Free text**: write a few sentences
- **Gap**: enter a single missing word

Single questions can be skipped. Whoever skips all of them gets A1 without the AI being asked. At
the end the level appears with a short reasoning.

## Cancelling and resuming

Cancel asks first, because the answers are lost. Reloading the page does no harm, the test picks
up at the last question.

## In which language

The test is in German. Questions and grading too, this cannot be changed.

## What the result does

The level applies in every workspace. It steers how hard the exercises in the language trainer
turn out and how thoroughly the chat explains. Under Language level you can retake the test
through Change level or set the level yourself. It is not an exam result.

## How reliable it is

The placement comes from an AI, which can make mistakes. It is a placement for the exercises, not
a certificate. Whoever rates themselves differently sets the level under Language level.
