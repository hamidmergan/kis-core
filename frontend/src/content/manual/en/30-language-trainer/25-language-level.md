# Language level

![The Language level page with level and ladder](/manual/{lang}/language-level.png)

Reachable through the gear icon in the top right, for every role holding the permission Own
language level and language test. While Use the language trainer is on, the language test can be
started here at any time, even if you dismissed the card above the workspace list.

- **Level**: the level from A1 to C2 with its name from the Common European Framework of
  Reference and one sentence on what it means. Below it says whether it comes from the language
  test or was chosen by hand, with the date
- **Ladder**: all six levels in a row, filled up to your own
- **Change level**: opens the list of levels with descriptions. The chosen level shows at the top
  right away as a preview, it is only stored with Apply. From there you can also retake the
  language test
- **Without a level**: two ways, Start the language test or Set level yourself. Only with a level
  does the language trainer appear in the workspaces
- **Use the language trainer**: the switch at the bottom of the page. Off removes the three tools
  from the studio, the adjustment to the level and the English translation line on vocab cards and
  glossary entries. The translation on the transcript is not affected. While it is off, the page
  shows only the switch

The level applies in every workspace. It is a placement for the exercises, not an exam result.
