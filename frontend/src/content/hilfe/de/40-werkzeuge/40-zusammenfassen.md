# Zusammenfassung

Bringt lange Dokumente sowie Audio- und Videoinhalte auf das Wesentliche.

![Das Werkzeug Zusammenfassung](/hilfe/{lang}/werkzeug-zusammenfassung.png)

## So geht es

Datei auswählen, auf Zusammenfassung erstellen klicken, warten. Umfangreiche Inhalte dauern
einige Minuten. Danach steht das Ergebnis zum Herunterladen bereit.

## Was Sie erwarten dürfen

Eine Zusammenfassung ist eine Verkürzung und lässt zwangsläufig etwas weg. Sie ersetzt das
Original nicht, wenn es auf Genauigkeit ankommt.

## Der Unterschied zum Chat im Modul

Das Werkzeug arbeitet mit einer einzelnen Datei und liefert einen Text zum Herunterladen. Der
Chat im Modul arbeitet über alle angehakten Materialien und belegt jede Aussage mit der Stelle,
aus der sie stammt.
