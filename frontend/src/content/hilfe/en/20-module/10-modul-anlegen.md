# Creating a module

![Creating a new module](/hilfe/{lang}/modul-anlegen.png)

On the start page **+ Module**, give it a name and a short description. Done.

## Getting participants in

Nobody is entered by hand. You create an **enrolment link** and pass it on. Whoever opens it
enrols themselves.

Under participants you make single people **tutors**. Tutors may do everything except deleting
and appointing further tutors.

## The menu of the module row

- **Participants**: list, appointing tutors
- **Enrolment links**: create and withdraw access
- **Edit**: name and description
- **Delete**: final, with everything attached

## A notice for everybody

A **notice** field above the list of materials holds a short text and links, for example to the
Moodle page. Everybody sees it, only those who run the module can change it.
